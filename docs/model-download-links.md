# Ссылки на модели

> **Сгенерированный справочник.** Файл содержит таблицы репозиториев, commit
> SHA и прямых ссылок на файлы моделей. Для установки используйте
> [`docs/installation.md`](installation.md); для повседневной работы —
> [`docs/usage.md`](usage.md).

Ссылки привязаны к commit SHA, который был актуален на момент генерации файла.
Для каждой версии нужны четыре репозитория: segmenter, segmenter tokenizer, statement, statement tokenizer.

Для одной версии с подробным прогрессом по каждому файлу:

```powershell
.\scripts\python.cmd .\scripts\download_model_version.py --version 3.6 --force
```

Для скачивания всех версий:

```powershell
.\scripts\python.cmd .\scripts\fetch_models.py --versions all --force
```

Монитор прогресса в OpenCode:

```powershell
.\scripts\python.cmd .\scripts\show_download_progress.py --watch --interval 5
```

Скрипты используют `HF_HUB_DISABLE_XET=1` и раскладывают файлы в `models/hf-cache`.

## Примечания

- `model.safetensors` — веса; `config.json` — архитектура; tokenizer-файлы — токенизатор.
- Для statement-моделей tokenizer вынесен в отдельный репозиторий (`...-tok`).
- Для segmenter токенизатор тоже вынесен отдельно (`...-tokenizer`).
- Если ссылка `resolve/<sha>` устарела, замените `<sha>` на актуальный commit из [Hugging Face](https://huggingface.co/syssec-utd).
- Все версии 3.6–3.15 уже скачаны локально; для принудительной повторной загрузки **всех** версий, включая 3.6:
  ```powershell
  .\scripts\python.cmd .\scripts\fetch_models.py --versions all --force
  ```
